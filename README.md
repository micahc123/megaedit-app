# Megaedit

The desktop app for making animated reels by writing a script. Mac and Windows.

Megaedit is for members of [Megamedia Labs](https://www.skool.com/mega-media-labs-6489). Members get a key that unlocks every style and full exports.

## Download

Get the newest version from the [Releases page](https://github.com/micahc123/megaedit-app/releases/latest).

| Your computer | File |
|---|---|
| Newer Mac, anything with an M chip | `Megaedit-1.0.0-arm64.dmg` |
| Older Intel Mac | `Megaedit-1.0.0-intel.dmg` |
| Windows 10 or 11 | `Megaedit-Setup-1.0.0.exe` |

Not sure which Mac you have? Apple menu, then About This Mac. If it says "Apple M", take the first one.

## Install on a Mac

1. Open the file you downloaded and drag Megaedit into Applications.
2. Open Megaedit. Your Mac says it can't check the app, because the app isn't registered with Apple yet. Press **Done**.
3. Open System Settings, go to Privacy & Security, scroll down and press **Open Anyway** next to Megaedit. You only do this once.

If your Mac says the app is "damaged", open Terminal, paste this line, press Return, and open Megaedit again:

```
xattr -cr /Applications/Megaedit.app
```

## Install on Windows

1. Open the file you downloaded.
2. Windows shows a blue "Windows protected your PC" box. Press **More info**, then **Run anyway**.
3. Follow the installer, then open Megaedit from the Start menu.

## What you need

- Claude Code, signed in with your own Claude plan. Megaedit uses it to write and fix your scripts, and never asks for your Claude login.
- Your Megaedit key. Paste it in the last setup step, or later in Settings, under Licence.
